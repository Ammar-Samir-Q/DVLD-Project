# Driving and Vehicles Licensing Department (DVLD)

A desktop application built with C#, .NET Framework, and SQL Server to manage and track driving license operations.

## About The Project

This is my first complete project built using the Three-Tier Architecture.

I spent around 1–2 months developing this project while following Course 19 by Dr. Mohammed Abu Hadhoud at Programming Advices.

It was an amazing learning experience. For the first time, I learned how to design and build a complete system from scratch, starting with an idea and turning it into a fully functional application.

More importantly, this project gave me the confidence to approach complex systems and believe that I can turn almost any idea into a working application.

Special thanks to Dr. Mohammed Abu Hadhoud for this valuable learning journey.

## Features

- Manage Driving Licenses
- Manage Drivers and Users
- Manage Applications
- Manage Tests and Test Types
- Create and Track Tests, including Vision Tests
- Track License and Application Operations

## How to Install

1. Download the installer from the [Releases](../../releases) section.

4. Wait for the installation to complete.
